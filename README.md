# ParaBank - Banking Application Testing

## Project Overview

A manual testing project performed on the ParaBank banking web application to validate core banking functionality, user workflows, input validations, transaction processing, and session management.

## Testing Scope

The application was tested across the following functional areas:

- Registration
- Login
- Account Overview
- Open New Account
- Transfer Funds
- Bill Pay
- Find Transactions
- Logout

## Testing Coverage

- 160 Test Cases
- 160 Test Scenarios
- 8 Functional Areas
- Positive and negative test scenarios
- Input and field validations
- Transaction and account workflows
- Session and access-control validation
- Defect identification and reporting

- Requirement analysis

Defects identified during testing were documented with reproducible steps, expected results, actual results, severity, priority, and supporting information.

Defects were reported and tracked using Jira.
